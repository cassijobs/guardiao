# Publicação segura da v5.0

## GitHub

Use a branch `guardiao-v5` durante os testes. Não apague a `main`.

Ao substituir os arquivos da branch, confirme que `404.html` ficou na raiz, ao lado de `index.html`.

## Supabase

Execute `sql/atualizacao_v5_0_completa.sql` antes de testar códigos curtos.

O reconhecimento não cadastra códigos automaticamente. Cada Artefato precisa ser cadastrado pelo SQL gerado em `admin-artefatos.html`.

## Endereços

- Página principal: `/guardiao/`
- Gerador: `/guardiao/admin-artefatos.html`
- Artefato: `/guardiao/MKS-7ZKC4`
- Formato de compatibilidade: `/guardiao/?artefato=MKS-7ZKC4`
