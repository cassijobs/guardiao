GUARDIÃO MASTER 6.1 — PUBLICAÇÃO

1. Extraia este ZIP.
2. Copie TODO o conteúdo da pasta guardiao para a pasta local clonada pelo GitHub Desktop.
3. Substitua os arquivos quando o Windows perguntar.
4. No GitHub Desktop: Commit to main e depois Push origin.
5. Aguarde o GitHub Pages concluir a publicação.
6. No Android, desinstale a PWA anterior e limpe os dados de cassijobs.github.io.
7. Abra https://cassijobs.github.io/guardiao/app/ e instale novamente.
